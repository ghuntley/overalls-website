# Agent guidance

## Git workflow

- We don't use pull requests. Commit and push directly to `main`.
- Don't create feature branches or open PRs for changes to this site.

## Editing pages

- The HTML pages are generated by `tools/site/`. Edit the generator (`pages_main.py`, `pages_guide.py`, `pages_security.py`), not the HTML.
- Rebuild with `python3 tools/site/build.py .` and check with `python3 -I tools/site/check.py .`, then commit the generator and HTML changes together.
